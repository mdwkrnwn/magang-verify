# PDF dan Rekap Logbook

Format mengikuti contoh dokumen logbook yang diberikan: identitas mahasiswa/mitra, tabel Hari/Tanggal, Jam Masuk, Jam Pulang, Kegiatan, serta area tanda tangan mahasiswa, dosen, dan pembimbing lapangan/mitra.

## Urutan
`Minggu 1 -> Minggu 2 -> Minggu 3 -> ...`

Gunakan `minggu_ke ASC` dan `tanggal ASC`.

## Download Semua
Contoh:
- Page 1 = Minggu 1
- Page 2 = Minggu 2
- Page 3 = Minggu 3

Jika satu minggu membutuhkan lebih dari satu halaman karena banyak baris, urutan minggu tetap harus terjaga.

## Signature
PDF hanya menampilkan signature yang benar-benar tersimpan.

## Histori
Download berdasarkan penempatan agar Magang #1 dan Magang #2 tidak bercampur.

## Security
Endpoint PDF wajib mengecek authentication, role, ownership/relationship, dan penempatan.
