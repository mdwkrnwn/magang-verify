# Menu Tendik dan Koordinator

## Tendik
Fokus pada administrasi dan validasi.

Jika mahasiswa tidak melakukan aktivitas pada suatu tanggal, mahasiswa mengisi aktivitas/alasan seperti sakit, izin, atau lainnya. Jika diperlukan, bukti dapat dilampirkan.

Tendik:
- melihat pengajuan validasi;
- memeriksa alasan/bukti;
- menyetujui;
- menolak dengan catatan.

## Koordinator Magang
Fokus pada:
- monitoring mahasiswa;
- monitoring mitra;
- monitoring penempatan;
- monitoring logbook;
- laporan;
- kontrol workflow sesuai kewenangan.

Tendik dan Koordinator tidak otomatis mendapat hak edit semua data hanya karena memiliki akses monitoring.
